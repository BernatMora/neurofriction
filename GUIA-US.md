# 📖 Guia d'Ús Ràpida - NeuroFriction v5

## 🎯 Pas 1: Descarregar l'App

### Des de GitHub:

1. Ves a: https://github.com/BernatMora/neurofriction
2. Fes clic al botó verd **"Code"**
3. Selecciona **"Download ZIP"**
4. Descomprimeix l'arxiu ZIP al teu ordinador
5. Busca l'arxiu `neurofriction-5.html`

### Alternativa - Clonar el Repositori:

```bash
git clone https://github.com/BernatMora/neurofriction.git
cd neurofriction
```

## 🚀 Pas 2: Obrir l'App

### En Ordinador:

1. **Localitza** l'arxiu `neurofriction-5.html` a la carpeta descarregada
2. **Fes doble clic** sobre l'arxiu
   - Si no s'obre automàticament:
     - Clic dret → "Obrir amb" → Selecciona el teu navegador (Chrome, Firefox, Safari)

### En Mòbil:

**Opció A - Des del mòbil directament:**
1. Descarrega el ZIP a través del navegador del mòbil
2. Utilitza l'app "Arxius" o un gestor de fitxers
3. Extreu el ZIP
4. Toca `neurofriction-5.html` i selecciona obrir amb el navegador

**Opció B - Transferir des de l'ordinador:**
1. Descarrega els arxius a l'ordinador
2. Connecta el mòbil amb USB
3. Copia `neurofriction-5.html` al mòbil
4. Obre l'arxiu amb Chrome (Android) o Safari (iOS)

**Opció C - Utilitzar un servidor (recomanat per mòbil):**
1. Puja els arxius a GitHub Pages, Netlify o Google Drive
2. Accedeix a la URL des del mòbil

## 🎧 Pas 3: Configurar i Començar

### Primera Vegada:

1. **Connecta auriculars** (molt important per l'àudio binaural)
2. Quan s'obri l'app, veuràs una pantalla amb diferents modes
3. **Selecciona un mode**:
   - 🆕 Principiants: **"NeuroExplora"** o **"Sessió Viva"**
   - 🧘 Meditació: **"Claredat Mental"**
   - 🧠 Avançat: **"Ment Superior"**

4. **Configura la sessió**:
   - Durada: 10-15 minuts per començar
   - Intensitat: "Mitjana"
   - Volum: Comença baix i augmenta gradualment

5. **Fes clic a "Iniciar"**
6. **Dona permís** quan el navegador demani reproduir àudio
7. **Tanca els ulls** i deixa't guiar

### Sessions Posteriors:

- Les teves dades es guarden automàticament (historial, progrés)
- Pots exportar les dades des del menú (botó 📥)
- Explora diferents modes segons el teu objectiu del dia

## 💾 Pas 4: Instal·lar com a App (Opcional)

### Android:

1. Obre `neurofriction-5.html` amb Chrome
2. Toca els tres punts (⋮) al menú
3. Selecciona **"Afegeix a la pantalla d'inici"**
4. Toca **"Afegir"**
5. Ara tens una icona a la pantalla d'inici! 📱

### iOS (iPhone/iPad):

1. Obre `neurofriction-5.html` amb Safari
2. Toca el botó de compartir ()
3. Desplaça't avall i toca **"Afegeix a l'inici"**
4. Toca **"Afegir"**
5. L'app apareixerà a la teva pantalla d'inici! 📱

### Windows/Mac/Linux:

1. Obre `neurofriction-5.html` amb Chrome o Edge
2. Cerca la icona d'instal·lació a la barra d'adreces (⊕ o ⬇)
3. Fes clic a **"Instal·la NeuroFriction"**
4. L'app s'obrirà com una finestra independent! 💻

## ❓ Preguntes Freqüents

**P: Necessito connexió a Internet?**
R: No després de la primera càrrega. L'app funciona offline.

**P: Es guarden les meves dades?**
R: Sí, localment al teu dispositiu. Usa Export/Import per fer còpies.

**P: Puc usar-lo sense auriculars?**
R: Pots, però perdràs l'efecte binaural (que és el més important).

**P: És segur per epilèpsia?**
R: Consulta amb el teu metge abans d'usar freqüències cerebrals.

**P: Puc personalitzar-lo?**
R: Sí! Usa l'editor de píndoles per afegir el teu propi contingut.

**P: Funciona en tots els navegadors?**
R: Millor en Chrome, Firefox, Safari i Edge moderns.
